# Agente 3D Pro Sistema web para validação geométrica, reparo de malha e preparação de perfil antes do envio ao Bambu Studio. ## Objetivo Este projeto foi pensado como uma camada de validação e préespera para impressão 3D, com foco em workflows compatíveis com Bambu Studio. Ele ajuda em: - validação de malha 3D - detecção de falhas em geometria - cálculo de volume, limites e extents - diagnóstico de watertightness e manifold - proposta de perfil de impressão para PLA/PETG/ABS/ASA - geração de manifesto de impressão e checklist final ## Importante Esse projeto não substitui o Bambu Studio como slicer principal. Ele é um pré-processador, validador e gerente de preparação. Para o arquivo final de impressão, o fluxo real continua sendo: 1. validar modelo 2. corrigir a geometria 3. preparar perfil do material 4. abrir arquivo no Bambu Studio 5. ajustar slicer final e gerar o G-code ## Estrutura do projeto - `app.py` - API FastAPI - `src/mesh_validator.py` - validação geométrica, regras de impressão e manifest - `templates/` - frontend web - `static/` - CSS/JS - `output/uploads` - arquivos enviados e manifests gerados ## Executar localmente ```bash python -m venv .venv source .venv/bin/activate pip install -r requirements.txt uvicorn app:app --host 0.0.0.0 --port 8000 --reload ``` Acesse: - http://localhost:8000 ## API ### Processar um arquivo ```bash curl -X POST "http://localhost:8000/api/process" \ -F "file=@modelo.stl" \ -F "material=PLA" \ -F "nozzle_mm=0.4" \ -F "profile_name=Bambu X1C" ``` ### Obter manifest ```bash curl http://localhost:8000/api/manifest/modelo ``` ## Regras de uso - modelos com malha não fechada devem ser reparados antes da impressão - perfis reais dependem de nozzle, material, ambiente e máquina - Bambu Studio continua sendo a fonte final para fatiamento e envio ao equipamento ## Melhorias futuras - export direto em 3MF - integração com fatiador local - visualização 3D interativa no navegador - maior camada de heurísticas para overhang, supports e warping
